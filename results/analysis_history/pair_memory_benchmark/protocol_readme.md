# Pairwise external memory experiment

This experiment compares learned historical and local key-value memory with a tuned feed-forward network on ordered pairs of MiniMol representations. The output is the difference in the transformed, oriented endpoint between the query and reference molecule. There are no sign-consistency constraints. The strict memory decoder reads retrieved vectors; the residual memory decoder also receives a direct query representation and a learned local residual correction.

Six endpoints are modeled separately, pooling human, rat and mouse within each endpoint where available. The existing five outer group splits and predictor training/validation roles are preserved. Historical banks and PCA use predictor training data only. The entire current source group is excluded from historical retrieval during training. Test outcomes are never used for configuration or checkpoint selection. Existing RL-role training data are unused so this experiment preserves the predictor/RL separation.

Each family receives eight predefined configurations. They vary original 512-dimensional input versus 32/64/128 principal components, encoder/decoder widths, query/key/value dimensions, historical memory capacity, attention temperature, sparse retrieval and learning rate. Screening uses 400 updates; two configurations per family, endpoint and fold receive 2,400 updates from a fresh initialization. The winner is repeated with two additional seeds. Checkpoints are selected using validation squared error, balancing zero and positive context and giving extra weight to large pools where validation coverage permits. Selection is independent within each endpoint and outer fold.

Training episodes choose large pools half the time and all pools half the time. At evaluation, the reference, revealed compounds and hidden query set are disjoint. The same query set is held hidden across context budgets. Large pools (at least 15 compounds) have five fixed hidden queries and 0, 1, 2, 4 or 9 additional measurements beyond the reference. Smaller pools use shorter curves. Ten independent splits of each test pool are averaged. References are random for prediction evaluation, rather than restricted to unstable hits used in acquisition experiments.

Comparators include the context-invariant FNN, measured-anchor averaging with that FNN, and a ridge correction on its frozen last hidden layer. Ridge regularization is selected on validation data. An expected-outcome control replaces revealed outcomes with each model's initial prediction, keeping revealed identities fixed. This tests whether observed surprises, rather than the presence of extra structures, drive improvements.

Primary results weight pools equally within each endpoint and then endpoints equally, using pools of at least 15 compounds. All-pool results are secondary. Report squared error, absolute error, R-squared and Spearman correlation with explicitly defined aggregation. Repeated seeds estimate training variability; paired uncertainty resamples source groups. This is a delta-prediction experiment, not a new acquisition-policy benchmark or a calibrated-uncertainty study.
