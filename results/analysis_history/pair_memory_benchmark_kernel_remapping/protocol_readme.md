# Tanimoto and covariance remapping experiment

The primary experiment holds each existing tuned conventional GP's linear mean and learned input geometry fixed. It fits only covariance amplitude, molecule-level residual variance and a small distance-to-covariance mapping. This isolates whether improved covariance helps learn from local measurements. All methods share the same zero-context point predictions. Six endpoints, five existing outer folds, three seeds, predictor-role development pools, and identical fixed hidden-query evaluation cases are retained. Configuration selection uses validation data.

The six families are a refitted current kernel control, a flexible remapping of the current kernel, direct MiniMol Tanimoto, remapped MiniMol Tanimoto, direct Morgan Tanimoto, and remapped Morgan Tanimoto. MiniMol candidates use either the original 512-dimensional representation or the existing GP's selected representation scaled by its learned length scales. The latter is usually training-only PCA. Tanimoto means the real-valued dot-product kernel $T(x,y)=\frac{x^\mathsf{T}y}{\|x\|^2+\|y\|^2-x^\mathsf{T}y}$, including the defined zero-vector extension. It is valid for signed vectors and is distinct from a nonnegative min-max coefficient. Morgan candidates use 2048-bit radius-2 or radius-3 fingerprints with chirality; on binary inputs dot-product Tanimoto equals intersection/union similarity. The mean remains a MiniMol linear mean even when the covariance uses Morgan fingerprints.

Valid positive-semidefinite mappings replace arbitrary scalar neural networks. For Tanimoto, $\exp[-\beta(1-T)]$ has a learned positive beta; a four-component nonnegative exponential mixture learns weights and beta values. For the current Euclidean geometry, candidates include nonnegative mixtures of powers 1,2,4,8 of its normalized kernel; mixtures of its kernel at five fixed length-scale multipliers; and a rational-quadratic function of squared scaled Euclidean distance with learned positive shape and scale. Each construction preserves a valid covariance. Residual variance is added per molecule before differencing, retaining correlated reference noise.

Twenty-two manually specified configurations receive 400 likelihood updates on seed 11. The best two per family, endpoint and fold are retrained for 2,400 updates. The best is repeated with two additional seeds, each using its corresponding existing GP mean and geometry. Step-zero checkpoints are eligible. Selection uses validation marginal negative log predictive density, with equal zero/positive-context weight and extra weight for adequately represented large validation pools. No new PCA dimension or neural feature extractor is fitted in this targeted covariance experiment.

A secondary practical comparison releases the linear mean weights: for each endpoint/fold, select the strongest alternative covariance family by validation score and jointly fine-tune it, alongside the current-kernel control, for up to 1,200 updates. This does not use test outcomes to select a kernel. Geometry remains fixed in this secondary experiment.

Report both accuracy/ranking and uncertainty: R-squared, mean fixed-query Spearman, negative log predictive density, interval coverage/width and standardized error, before and after one validation-fitted variance multiplier. Primary pools have at least 15 compounds, one reference and five fixed hidden queries; additional labels are 0,1,2,4,9. Ten draws per test pool and three model seeds are averaged. Smaller pools receive shorter matched curves. Confidence intervals resample source groups in a paired endpoint-stratified bootstrap. The experiment evaluates prediction, not acquisition policies.
